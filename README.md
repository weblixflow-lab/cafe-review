# RKN Devl Cafe — End-to-End Customer Journey Demo

## Included
- Welcome screen and step progress
- 1–5 star rating selection
- Rating-based preset suggestions (simulated AI)
- Editable customer feedback and optional name
- Review preview, demo confirmation and Google Reviews placeholder
- Restart journey button
- Black Cherry + Cream Vanilla mobile-friendly theme

## Demo-only limitations
- Reviews are not saved.
- Suggestions are predefined, not generated by a live AI model.
- Google Reviews is a placeholder; it does not open an external Google page.
- Clearly tell the client this is a prototype.

## Run
Requires Node.js 20.9+.
```bash
npm install
npm run dev
```
Open http://localhost:3000.

For a client to scan a QR with their own phone, deploy to a public HTTPS URL and create a QR pointing to that URL. Localhost won't open from the client's phone.
